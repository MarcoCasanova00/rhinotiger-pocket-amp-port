# ALGORITHM on MAIN: the kit. Forward, one part or a few of those heard another type as the next bar begins (the turns
# of a bar together: three, three parts); back, the kit before; none before, nothing. Only the parts heard change.
# COLD SIGNAL, 152: a bar is 1.58 s.
listen
wait 600
expect page 0
expect kits 0
turn ALGO 1
wait 50
said KIT
expect kits 0
shot kit-turn.png
wait 1700
expect kits 1
expect kit_n >0
expect kit_n <3
said KIT
shot kit.png
# three turns within a bar: three parts, at the next bar
turn ALGO 3
wait 50
expect kits 1
wait 1700
expect kits 2
expect kit_n 3
# back twice: the world's own types again
turn ALGO -2
wait 50
said KIT BACK
shot kit-back.png
wait 1700
expect kits 3
expect kick_type 0
expect bass_type 0
expect perc_type 0
expect line_type 0
expect events_type 0
expect atmos_type 0
# back again: none before, nothing changes
turn ALGO -1
wait 50
said NONE BEFORE
shot kit-none.png
wait 1700
expect kits 3
